# Política de Segurança - Plexus Browser

Este é um projeto pessoal de **hobby**. Mesmo sendo experimental, a segurança de quem for testar o navegador é levada a sério.


## Versões Suportadas
Apenas a versão mais recente na branch `main` recebe atualizações e correções de segurança.


## Como reportar uma vulnerabilidade

Se você encontrar alguma falha de segurança, problema no isolamento de sessões ou risco de vazamento de dados:

1. **Por favor, não abra uma Issue pública.**
2. Vá até a aba **[Security](https://github.com/claytonCharles/plexus-browser/security)** deste repositório e clique em **Report a vulnerability** (Relatório privado).
3. Descreva o problema encontrado e, se possível, como reproduzir.

Por ser um projeto pessoal, responderei e investigarei o relato assim que possível. Muito obrigado por ajudar a manter o projeto seguro!


Agradecemos pelo apoio em manter o projeto seguro para todos!
