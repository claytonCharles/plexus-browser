# 🕷️ Plexus Browser

Um navegador desktop experimental, desenvolvido como projeto pessoal de hobby.

### Objetivo de Funcionalidades

- [ ] Controle Avançado de Sessões
- [ ] Multi-View com Isolamento de Sessão
- [ ] Funcionalidade de Navegador Comum
- [ ] Ferramentas para Desenvolvedores (DevTools Integrado)
- [ ] Controle de Barra Lateral e Abas (Estilo Opera)
- [ ] Controle de Proxy por Sessão
- [ ] Bloqueio Nativo de Rastreadores
- [ ] Telas Gerais do Navegador (Home, Settings, History, etc...)
- [ ] Painel Interno de Produtividade (Bloco de notas, alarmes, etc...)
- [ ] Integração de IA Local
